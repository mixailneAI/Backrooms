## Команды (из корня репозитория)

    node systemtools/gates.mjs             — парсер + doctor + headless (без git)
    node systemtools/push.mjs "сообщение"  — гейты -> коммит -> fetch/rebase -> пуш -> стук сайта
    node systemtools/doctor-runner.mjs     — pure-read: архитектура / геометрия / маршрут
    node systemtools/pwa-runner.mjs        — регенерация sw.js, кэш-манифеста, иконок
    node systemtools/fix-runner.mjs r.json — единственные скриптовые правки (якоря, атомарно)
    node systemtools/audit-gen.mjs         — промт-пак внешнего аудита (ревьюер, не редактор)

## Правило

Done без зелёного гейта не существует (ТЗ 10.6). SKIP = честно «не проверялось», не «готово».
